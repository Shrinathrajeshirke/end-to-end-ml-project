A. AWs setup
1. create IAM user for github actions
    1. go to aws console -> IAM -> Users
    2. click "create users"
    3. give username
    4. Select: "Access key - Programmatic access"
    5. Click "Next: Permissions"
    6. Click "Attach existing policies directly"
    7. Select these policies:

        AmazonEC2ContainerRegistryFullAccess
        AmazonEC2ContainerRegistryPowerUser
    8. Click next -> create user
    9. click on created user -> security credentials -> create access key 
    10. select CLI method -> check the understand box -> provide in description "For GitHub Actions CI/CD deployment"
    11. click create access key
    12. download the .csv for credentials
    13. click done.
2. create ECR repository
    1. go to console -> ECR -> Repositories
    2. Click 'create repository'
    3. Visibility: Private
    4. provide name
    5. click "create repository"
    6. note the repository URI
3. Launch EC2 instance
    1. EC2 dashboard - launch instance
    2. Configure:
        Name: ml-app-server
        AMI: Ubuntu Server 22.04 LTS
        Instance type: t2.medium (recommended) or t2.small
        Key pair: Create new
            Name: ml-app-key
        Download ml-app-key.pem - SAVE THIS FILE!
    3. Network Settings:
        Create security group: ml-app-security-group
        Add rules:
        SSH (22) - Your IP
        HTTP (80) - 0.0.0.0/0
        Custom TCP (5000) - 0.0.0.0/0
    4. Storage: 20 GB gp3
    5. Click "Launch instance"
    6. Note your EC2 Public IP (e.g., 54.123.45.67)
4. Create IAM Role for EC2
    1. IAM → Roles → Create role
    2. Trusted entity: AWS service → EC2
    3. Permissions:
        AmazonEC2ContainerRegistryReadOnly
        AmazonEC2ContainerRegistryFullAccess
    4. Role name: EC2-ECR-Access-Role
    5. Click "Create role"
5: Attach IAM Role to EC2
    1. EC2 Dashboard → Select your instance
    2. Click on instance ID -> Actions → Security → Modify IAM role
    3. Select: EC2-ECR-Access-Role
    4. Click "Update IAM role"

B. Setup EC2 instance
1. connect to EC2 
    1. click on EC2 ID
    2. click on connect 
    3. keep default and connect to server
2. Install Docker on EC2
    1. update system
    -- sudo apt-get update -y
    2. install Docker
    -- sudo apt-get install -y docker.io
    3. start Docker
    -- sudo systemctl start docker
    -- sudo systemctl enable docker 
    4. Add ubuntu user to docker group
    -- sudo usermod -aG docker ubuntu
    5. verify installation
    -- docker --version 
3. Install AWS CLI on EC2
    1. update packages
    -- sudo apt update
    2. install unzip if not present
    -- sudo apt install unzip -y 
    3. Download the AWS CLI v2 installer
    -- curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
    4. Unzip the installer
    -- unzip awscliv2.zip
    5. Run the install script
    -- sudo ./aws/install
    7. Verify installation
    -- aws --version
    8. test IAM role
    -- aws sts get-caller-identity
4. Test ECR access
    1. get your AWS account ID
    -- export AWS_ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
    -- echo $AWS_ACCOUNT_ID
    2. login to ECR
    -- aws ecr get-login-password --region us-east-1 | \
       docker login --username AWS --password-stdin \
       $AWS_ACCOUNT_ID.dkr.ecr.us-east-1.amazonaws.com
5. Exit and reconnect
    1. exit EC2
    -- exit
    2. reconnect (## not required)
    -- ssh -i ml-app-key.pem ubuntu@EC2-public-IP
    3. verify docker works withoud sudo
    -- docker ps 

C. setup github secrets 
1. Go to GitHub Repository
    1. Open your repository on GitHub
    2. Click Settings (top right)
    3. Click Secrets and variables → Actions
    4. Click "New repository secret"
2. Add AWS Credentials
    1. Secret 1: AWS_ACCESS_KEY_ID
    Name: AWS_ACCESS_KEY_ID
    Value: Your IAM user access key ID (from Step 2.1)
    Click "Add secret"
    2: AWS_SECRET_ACCESS_KEY
    Name: AWS_SECRET_ACCESS_KEY
    Value: Your IAM user secret access key (from Step 2.1)
    Click "Add secret"
    3. EC2_HOST
    Name: EC2_HOST
    Value: Your EC2 public IP (e.g., 54.123.45.67)
    Click "Add secret"
    4: EC2_SSH_PRIVATE_KEY
    Name: EC2_SSH_PRIVATE_KEY
    Value: Contents of ml-app-key.pem file
